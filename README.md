# 千鱼（Qianyu）

Windows 上的 QQ 桌面机器人。它基于 [MaiBot](https://github.com/Mai-with-u/MaiBot) 1.3.19 二次开发，用 DeepSeek API 做对话后端，通过官方 NapCat 连接 QQ（运行时按需下载，不把 NapCat 或 QQ 的二进制打进仓库）。

当前公开版本是 **0.3.14 中性纯净版**：新安装不附带人格、说话风格、个人记忆或知识，也不包含任何人的 QQ 登录态或 API 密钥。你需要自行填写 API、登录自己的 QQ，再按需要添加资料。

> 本仓库只发布通用源码和模板。安装器 EXE 目前是未签名预览版（`unsigned_preview`），开源不能替代 Windows 代码签名，下载或运行时仍可能出现 SmartScreen 提示。

## 它是怎么工作的

千鱼把三件事叠在一起，变成一个可安装的 Windows 桌面应用：

1. **桌面壳与管理台**（`fatfish/`）  
   用 Python + pywebview / WebView2 提供中文管理界面，负责实例目录、生命周期、文件知识检索，以及安装、升级、启动。

2. **聊天核心**（`engine/MaiBot/`）  
   使用锁定版本的 MaiBot，并在 `upstream.lock.json` 里记下本地修改边界。模型调用走你自己配置的 DeepSeek（或其他兼容）接口。相关人格、聊天记录和资料会发送给该服务商，请只填写自己的密钥。

3. **QQ 连接**（`components/` 与运行时组件）  
   通过 MaiBot 的官方 QQ 连接器和 NapCat 接入 QQ。NapCat 在首次运行时从官方来源下载，并须遵守其有限分发许可；QQ 客户端由使用者自行准备，本仓库不包含二者的二进制。

安装与启动入口是 C# 原生安装器 / 启动器加 Python 安装逻辑，普通用户不必再跑 PowerShell 脚本。构建、白名单打包和签名注意事项见 [`源码发布说明.md`](源码发布说明.md)。

### 0.3.14 里比较重要的行为

- **人物身份**：普通群聊会结合 QQ 头像和大肥鱼角色自称，识别并记下“这条是鱼还是人”。只有被确认的鱼，才会受同一话题最多三轮回复的限制；识图不可用时保持未知，也可以在界面里手动纠正。
- **接话**：群聊支持回应明确呼叫、延续尚未结束的话题，以及按滑块概率开启新话题。完整回答不会立刻关掉追问窗口；明确结束、连续未命中或超时才会收束。
- **记忆**：自动长期记忆默认关闭。若你自行开启，同一 QQ 账号的私聊和群聊可以按账号互通近期与长期记忆，不会把别人的私聊或未知来源混进去。
- **升级**：用新版安装器指向原目录时，会先备份再更新通用程序；记忆、知识、账号和你自己改过的人格会保留。不要用“解压覆盖整个目录”代替升级，也不要对外分享备份。

更完整的操作步骤见 [`操作手册.md`](操作手册.md)，版本细节见 [`docs/程序说明.md`](docs/程序说明.md)。

## 从源码构建

需要 Windows x64、Python 3.12，以及系统里可用的 .NET Framework C# 编译器。在程序根目录运行：

```text
py -3.12 scripts/build_desktop.py
```

构建器只用 Python 标准库，会编译安装器、安装助手和启动器，并按白名单生成纯净包、`SHA256SUMS` 和发布校验 JSON。没有可信代码签名证书时，产物必须标明 `unsigned_preview`，不能写成“已被 Windows 信任”。

私钥和证书不要提交到仓库。更完整的构建与签名说明见 [`源码发布说明.md`](源码发布说明.md)。
