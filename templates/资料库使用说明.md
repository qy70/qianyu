# 我的资料在哪里，怎样添加内容

这里的中文文件夹是实际资料的目录入口，编辑后就是原文件，没有两套副本。

| 文件夹 | 用途 | 怎样修改 |
|---|---|---|
| 01-人格 | 基础人格 | 编辑 identity.md；停止再启动核心 |
| 02-手写记忆 | 主人明确告诉千羽的事 | manual.md 是页面里的短背景；更长的内容放 notes 子目录，支持 Markdown / TXT |
| 03-知识库 | 项目资料、游戏设定、术语、知识文章 | 直接放 UTF-8 的 .md / .txt；可以分类建子目录 |
| 04-说话风格 | 可选的自定义表达 | 新实例为空；用户可以添加自己的风格文件与 manifest.json，明确启用后使用 |
| 05-自动记忆 | 聊天自动提炼的长期记忆 | 不要手改数据库；从软件的完整记忆管理查看 |
| 06-账号与配置 | API 密钥和核心配置 | 通常从软件连接设置修改；不要发给别人 |
| 07-QQ登录资料 | 小号登录态与 QQ 缓存 | 自动维护；不要发给别人 |
| 08-表情包 | 已导入和聊天收集的表情原图 | catalog.json 是初始图库索引，来源说明在子目录；自动收集由软件开关控制 |
| 09-自主资料 | 自主昵称和头像授权及审计 | preferences.json 的 enabled=false 可关闭；只操作绑定的小号 |

## 像写笔记一样添加记忆

打开 `02-手写记忆/notes/00-核心记忆.md`，写最需要千羽一直记住的事实，例如名字、关系、偏好。每轮附带开头最多 1800 字符；其余内容仍可按相关性选取。

更长的经历可新建 `notes/人物关系.md`、`notes/共同经历.md`。知识文章放 `03-知识库`。用清楚的标题和主题词，效果比堆满无关内容好。不用把所有内容塞进页面里的 12000 字符输入框。文件不能直接使用 Word、PDF、图片；先转为 UTF-8 Markdown 或 TXT。

文件通常 5 秒内在后续回复中使用。资料页“刷新资料列表”可检查可读文件和错误，但不会强迫一个已运行的回复立刻重读。每轮最多选约 6000 字符，属于本地关键词检索，不保证记住或命中所有资料。当前扫描最多 500 份、单文件 2 MB、合计 20 MB；超限或编码错误会在资料页提示。以 `_` 开头的说明文件不参与读取。

manual.md、identity.md，以及风格包 persona.md / reply-style.md 修改后请停止再启动核心。其他风格规则和示例在后续回复中读取。风格包 enabled=false 只关闭风格，不关闭手写记忆/知识读取。

## 分享哪一份

只分享 `02-纯净分享版` 中新生成的 ZIP。里面是程序与通用模板，对方安装后填写自己的 API、扫码自己的小号，创建自己的资料。纯净版不附带人格、风格、示例、记忆或知识；由接收者自行添加。

不要分享 `01-我的千鱼`、整个项目文件夹、个人备份、账号配置或 QQ 登录资料。自动记忆与聊天数据库不同，原始聊天历史仍由程序内 data/MaiBot.db 管理。

## 识图、表情和自主形象

连接设置可开启图片理解；DeepSeek deepseek-flash 支持图像输入。当前模型需要支持图片；高级设置已有独立视觉模型时会保留，不必另配同一个接口。自动图片长期记忆仍是独立能力，并非开启看图就自动记住全部图片。

“人格与记忆”可开启从聊天收集表情。表情库当前上限至少 256 张，单张收集最大 5 MB；自动筛选注册由上游原生机制完成，不保证每张都收藏。软件发送使用原生 send_emoji 或千羽的 qianyu_sticker，真正发送图片，不是文字假装发图。

自有社交插件含 qianyu_gallery、qianyu_sticker、qianyu_profile。纯净版默认不授权自主改资料，也不附带原使用者的图库。preferences.json 写入主人和绑定小号后才可启用，模型不能通过聊天自行授权。头像从本实例图库选择；QQ 接口若拒绝，日志会记录失败。核心名字与主人关系独立于 QQ 展示昵称。

可手动停止核心后运行 scripts/import_nekowhale.py，为自己的实例获取作者公开的千羽图库；它不安装 DeepSeek Harness，使用作者资源时保留署名并遵守非商业使用约定。初始图库和私人授权均不进入纯净发行包。


## PNG 美图与空白头像修复（0.3.2）

“10-PNG头像与美图”是独立 PNG 形象库，里面的“图片预览.html”可直接双击浏览。千羽可调用 qianyu_gallery(kind=avatar) 获取带数字的真实图像预览，数字与完整编号对应，再用 qianyu_profile 选择；不用让她盲猜动图编号。scripts/import_portraits.py 可从公开档案导入到自己的实例，逐张保存固定来源和哈希，不进入纯净分享包。

动图头像会抽样检查多帧，跳过透明与纯色画面后选非空主体；所有候选都为空则拒绝上传。原图/动画保持原样，头像仅作所需的静态 PNG 处理。QQ 已确认设置并不保证所有客户端缓存立刻刷新。

qianyu_sticker 发送成功使用上游原生 stop_after_execution 结束当前回合，避免重复生成额外回复；需要文字时先发文字再用表情收尾。另在拆句前及真正发送前拦截内部消息标签，正常图片与普通 XML 示例保留。
