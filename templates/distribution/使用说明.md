# 千鱼 0.3.14 纯净版

软件名“千鱼”，界面主题与形象主体“大肥鱼”；个人鱼名和人格独立设置，已有资料保留。

首次使用先看同目录的“操作手册.pdf”，可编辑原稿为“操作手册.md”。

0.3.14 已修复旧包在默认 Windows 脚本策略下无法安装的问题：安装和启动不再调用 PowerShell 脚本，也不会修改系统安全设置。当前预览包仍未签名，未知发布者或 SmartScreen 提示需要后续可信代码签名及正式发布渠道处理，不能靠开源或 SHA256 自动消除。详情见 程序/源码发布说明.md。

1. 使用“千鱼-0.3.14-安装.exe”时，双击并按提示选择位置；首次可用 %LOCALAPPDATA%\Fatfish，升级选择原安装目录。程序先备份再退出旧版并更新。使用 ZIP 时，完整解压后双击“安装千鱼.cmd”。两者都会准备 Python 3.12、桌面网页组件和固定依赖，首次需要联网。
2. 后续双击“启动千鱼.cmd”或桌面“千鱼”快捷方式。
3. 填入自己的 DeepSeek API，扫码登录自己的 QQ 小号，选择聊天范围，再启动核心。

第一次打开后会在这里创建“我的资料”，里面的中文文件夹通往实际人格、手写记忆、知识库、风格与自动记忆。详细说明在“我的资料/先看这里.md”。手写记忆可编辑 02-手写记忆/notes/00-核心记忆.md；知识文章直接放 03-知识库，支持 UTF-8 Markdown 和 TXT。

新安装不带任何预设人格、语气、风格包、示例、个人记忆或知识，默认名字 DeepSeek，仅保留通用 AI 助手身份；自动长期记忆与表情收集默认关闭。

升级保留记忆、知识、账号与用户自定义人格/风格，只清理准确匹配旧版出厂指纹的模板。备份在安装目录旁“千鱼升级备份”。这是下载新版 EXE 后自动覆盖升级，不含联网检查和自动下载。

本版默认启用话题接话：回应明确呼叫、按需延续活动话题，无人呼叫且没有活动话题时，按“人格与记忆”的新话题概率尝试参与。默认 5%，没有额外乘数；0% 仍可回应呼叫与续聊，100% 不代表逐条回复。完全暂停请点击“休息一下”。普通完整回答后仍追踪三条有效新消息，续聊命中后重新数三条；明确结束、连续三条未命中或超时则关闭。呼叫词设置在“我的资料/09-自主资料/topic-reply.json”，修改后重启核心。

“程序”是内部源码与运行数据，一般不必进入。对外分享请从软件“数据与扩展”重新生成纯净包，不要压缩已经用过的整套目录。个人内容保存在 程序/instances，备份也可能含密钥。

这是联网源码安装包，未在另一台全新电脑完整验收，不是免依赖离线包。NapCat 首次运行从官方获取，遵守其分发许可；其他源码来源和许可见 程序/THIRD_PARTY.md。

界面为大肥鱼 Q 版美图与半透明蓝色主题；图片署名、来源和非商业使用说明可在“插画与鸣谢”及 程序/fatfish/web/assets/ATTRIBUTION.md 查看。个人鱼的昵称与人格可自行设置，兼容的启动文件和目录名称保留。
